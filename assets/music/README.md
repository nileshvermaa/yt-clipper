# Background music

Put royalty-free tracks here (`.mp3`, `.m4a`, `.wav`, `.ogg`, `.flac`). `clipper explain` mixes one quietly
(about -21 dB, faded in and out, looped) under the voice-over; the same script always gets the same track.
With no tracks here, videos are made without music.

Free source: YouTube Studio > Audio Library (filter "No attribution required"). The audio files are not
committed to git.
